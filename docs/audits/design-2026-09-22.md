# Design audit — the web portal against its design handoff

**Date:** 2026-09-22 · **Scope:** `apps/web` Director portal (P-track screens + shell)
**Source of truth:** the Claude Design project `5dd266f3-42e7-403f-b941-95c8e6551dc6`, mirrored at
`design-reference/portal/` (`HANDOFF-README.md` is the spec; each `.dc.html` is its screen).
**Method:** four parallel passes over shell + Inicio + auth, Movimientos + Estados + Productos,
Equipo + Empleados + Sincronización, and Negocio + Suscripción + Avisos + Asesor; every finding
below was re-verified against the code by hand.

> **Mirror freshness.** Checked against the live design project: the mirror matches. `ADDENDUM.md`
> (which documents Avisos, Asesor, Revisión de caja and Cortes de turno — the four screens with no
> README section) was missing and has been added.

Deliberate deviations (ADR-058/059/080/081) are listed in §5 and are **not** findings. Anything in
§2–§4 is drift: the design is the specification, and code that disagrees with it is wrong
(ADR-058).

---

## 1. Verdict

The **foundations are right**: every colour, radius, border width, shadow and the type ramp match
`colors_and_type.css`; fonts are self-hosted and capped at weight 800; the focus ring, the press
"stamp", the card hover lift, the button/input/tab/table/drawer geometry and the empty/error cards
are built to the spec's numbers. The sidebar (248/84, 1024px rail), the 76px brand block matching
the header, the 1760px cap and `28px 32px 96px` main padding are all exact.

What drifts is **completeness**, in three recurring shapes:

1. **States that cannot happen** — the `loading` state exists nowhere; `empty` is unreachable on
   four screens.
2. **Data the design shows that our queries never select** — operator, device, folio, time, sync
   status on ledger rows; shift state and today's takings per operator; contract, ingreso and app
   access per employee.
3. **Placeholders where a designed element should be** — blank icon tiles, text glyphs instead of
   SVG, one pill colour where four are specified, and several style blocks that are written,
   correct, and imported nowhere.

Judgement calls:

- **The animation literals are mostly legitimate.** The design says the scenes are authored on a
  fixed 460×200 canvas where "every inner size is a plain pixel value". The fix is a scoped lint
  exception for `login/escena-*` and `animation*.css.ts`, not a rewrite.
- **`rgba(13,13,13,0.45)` is the design's own drawer scrim** — it should use the `scrim` token.
- **The 3px coin border** is specified by the design; it wants a token, not a literal.
- **`#d4a017` and `colors.red`-as-text are real defects.**
