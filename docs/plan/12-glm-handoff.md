## 0. Working rules (learned the hard way — please keep them)

1. **The main checkout is shared.** Several agent sessions edit `~/Downloads/Cachink` on `main`
   concurrently. Never commit a file that holds someone else's uncommitted hunks. Check
   `git status` / `git diff` first. Do real work in a **git worktree** on a `track-n/*` branch.
2. **Push from a clean worktree**, not from the shared checkout: the pre-push hook runs
   lint/typecheck/test on the tree it runs in, and other sessions' unfinished files fail it.
   Flow: `git fetch && git merge origin/main` → `pnpm typecheck && pnpm lint && pnpm test` →
   `git push origin HEAD:main`. On rejection, fetch, merge, re-check, retry. **Never force-push,
   never `--no-verify`** (commit or push).
3. **Known flaky tests** (re-run once, don't "fix" by disabling): a `packages/ui` timeout,
   `apps/backoffice/tests/service-role-guard.test.ts`, `scripts/lint-coverage.test.ts`. Also
   `format:check` fails on 5 pre-existing docs (`docs/audits/db-2026-09-17.md`, 4 files in
   `docs/legal/aviso/`); not a gate.
4. **Migrations.**
   - data-pg: next free number **0020** (`packages/data-pg/drizzle/`). Hand-written and
     drizzle-generated files share the number space; `db-local.sh` and `db:migrate:hosted` apply
     alphabetically. Tell the portal owner which number you take before pushing.
   - backoffice: next free **0011** (`apps/backoffice/src/server/db/migrations/`).
   - **Never GRANT anything on the `auth` schema** (hosted `postgres` has no GRANT OPTION there; a
     static test, `packages/data-pg/tests/hosted-auth-grants.test.ts`, enforces it). Read
     `auth.users` through a pinned `SECURITY DEFINER` function (patterns: `0011_owner_email`,
     `0014_tenant_fiscal`, backoffice `0010_admin_user_email`).
   - Every schema change needs an old→new migration test (CLAUDE.md §2.9). Test against a
     **throwaway** Postgres container, never the shared `xangarro-pg`.
   - Apply to the hosted **test** project with `pnpm --filter @xangarro/data-pg
db:migrate:hosted --dry-run`, then without `--dry-run`. Inputs come from the owner's gitignored
     `packages/data-pg/.env.local` (Session pooler URL + role passwords). **Never print it.**
5. **ADRs:** next free **ADR-086**. Any decision that overrides an existing ADR/Q needs one.
6. **Ownership.** The "Xangarro Web Portal" session owns `apps/web` UI outside Track N areas,
   `packages/data-pg` non-billing, sync/auth/session, and P-_ tasks. The "Operador" session owns
   Track O (`docs/plan/10-operador_.md`, `apps/web/src/operador/**`). Track N owns
`apps/backoffice`, `apps/web/src/server/billing/**`, `packages/application/src/{billing,cfdi,email,usage}`,
`packages/email`, `packages/auth-core`, `@xangarro/domain/{usage,onboarding}`. Coordinate through the
owner (or `SendMessage` if your harness has it) before touching another session's area.
7. **Secrets:** never ask for, print or commit them. The owner puts them in Vercel / `.env.local`.
8. **CLAUDE.md is human-only** — don't edit it. Plan progress goes in `docs/plan/*.md`
   (append Progress/Done lines; never renumber tasks).
